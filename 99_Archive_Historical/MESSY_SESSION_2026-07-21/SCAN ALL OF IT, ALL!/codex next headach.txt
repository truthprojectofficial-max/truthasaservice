    Order Get It Right is a deterministic, air-gapped Python audit engine. It scans business text for 54 hand-curated

    index via a Cox-Ross-Rubinstein binomial lattice, seals every action to a SHA-256 Merkle chain, and drafts ACL
    s.56 demand letters and s.177 expert-affidavit language.

    Why it is a legitimate engineering artefact:
    - The code runs, tests pass, and the chain verifies.
    - It has a real, enforced architecture: 00-99 spatial boundary, AST-enforced imports, no-network runtime,
    canonical-JSON rule, named-operator constant, Tau 10% extraction ceiling.
    - The methodology is written out in human-readable math docs, not hidden in a model.
    - It produces reproducible verdicts for the same input and config.
    - The operator (Justin Barnett) has documented build acceptance gates, a maintenance rhythm, a 1-2-3 backup plan,

    Why it is not "legitimate" as a commercial legal product today:
    - The 54-pattern ontology is validated against only 8 synthetic EVAL cases plus one pre-2021 reference corpus.
    That is far too thin for a tool that drafts court-facing affidavits.
    - The optionality lattice uses hard-coded inputs (S0=55.0, K1=18.0, K2=10.0) that do not derive from the audited
    business. The docs now honestly call this an "optionality index, not a valuation," which is good, but a naive
