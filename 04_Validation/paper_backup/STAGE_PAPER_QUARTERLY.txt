next to the laptop. Run it on the first Monday of January, April,
July, and October. This is a half-day, not a 15-minute job.

--------------------------------------------------------------------------------
THE ONE-LINE SUMMARY
--------------------------------------------------------------------------------
  8 hours (two half-days). Re-read every 04_Validation/, 00_Strategy/,
  and 01_Methodology/ doc. Re-burn the USB. Print a fresh paper
  card. Test the offsite copy. Seal a QUARTERLY_REVIEW block.

--------------------------------------------------------------------------------
TRIGGER
--------------------------------------------------------------------------------
  - First Monday of January, April, July, October.

--------------------------------------------------------------------------------

  [ ] 7. Run the full evaluation suite:

        python -m src.audit_cli --inbox ../data/inbox --outbox ../data/outbox
        Expected: all 8 EVAL cases pass.

  [ ] 8. Walk the build folder for any TODO / FIXME markers.
        Expected: zero.

  [ ] 9. Run the boundary test:
        python -m pytest tests/test_00_99_boundary.py
        Expected: 3/3 pass.

  [ ] 10. Run the normalize test:
         python -m pytest tests/test_normalize_regression.py
         Expected: 2/2 pass.

  [ ] 11. Run the full test suite:
         python -m pytest tests/
         Expected: 73 pass + 0 skip-guard on this host (with
         qwen3.5:9b + FastAPI up; live 2026-07-17). On a
         source-only host (the USB after a fresh burn; the SDXC),
         expect 71 pass + 2 skip-guard. See STAGE_PAPER_WEEKLY for
         the per-skip explanation.

  [ ] 12. Run the orchestrator determinism test:
         python -m pytest tests/test_smoke.py::test_evaluation_suite_is_deterministic -v
         Expected: passes.

PART C  --  1-2-3 BACKUP REFRESH (2 hours)
--------------------------------------------------------------------------------

  [ ] 13. Re-burn the build folder to a fresh USB stick
         (1-2-3 Step 1). Use the deploy/deploy-burn-usb.ps1
         script or copy the project tree by hand.

  [ ] 14. From the USB stick, run:
         python -m pytest tests/
         Confirm 71 pass + 2 skip-guard (the USB is a source-only
         copy, so the Tauri junction skip applies) or 77/0 if
         qwen3.5:9b is also loaded on the USB host. The USB must
         run the same tests as the laptop's source-only paths. If
         it does not, the build is not portable yet -- this is a
         real issue, not paperwork.

  [ ] 15. Print the current Merkle root on a fresh paper card
         (1-2-3 Step 2). The card is pinned to the inside cover of
         the printed Operator Manual. Update
         04_Validation/hardcopy/QUICK_REFERENCE_CARD.txt with the
         same root.

  [ ] 16. Test the offsite copy: take the second USB stick out of
         the bank safe deposit box, plug it in, run
         python -m src.verify_chain
         confirm the root matches the paper card, put the stick
         back (1-2-3 Step 3).

  [ ] 17. onyx> seal QUARTERLY_REVIEW_<Q>_<YYYY>

               "usb_burned": true,

  [ ] 18. onyx> verify
         Confirm the chain is intact after the seal.

  [ ] 19. Append a type: "change" entry to 04_Validation/changelog.log
         summarising the quarterly review. Then append a second

IF A STEP FAILS
--------------------------------------------------------------------------------
  - any test count drops           -> INCIDENT. Fix before
                                       continuing the cycle.
  - USB stick does not run tests   -> The build is not portable.
                                       This is a real portability
                                       regression. STOP. Fix the
                                       portability issue. Re-burn.
                                       This is the most important
                                       step in the whole maintenance
                                       plan.
  - offsite copy root does not
    match paper card               -> The 1-2-3 backup is broken.
                                       Re-burn the offsite stick.
                                       Update the paper card. Re-test.
  - onyx> seal fails               -> Check the payload JSON. Try
                                       again. If it still fails,
                                       INCIDENT.
