**Files:**
- Modify: `02_Technical/tools/agentic_repl.py`

The function uses `urllib.request` to POST to `http://127.0.0.1:11434/api/chat`. Replace with `subprocess` calling `curl`:

```python
import subprocess
import json

def call_ollama(prompt, model='minimax-m3:cloud'):
    result = subprocess.run(
        ['curl', '-s', '-X', 'POST', 'http://127.0.0.1:11434/api/chat',
         '-H', 'Content-Type: application/json',
         '-d', json.dumps({'model': model, 'messages': [{'role': 'user', 'content': prompt}], 'stream': False})],
        capture_output=True, text=True, timeout=60
    )
    return json.loads(result.stdout)
```
